# Deliberately rejected fixtures

These are altered copies of the synthetic fixture, not official geometry:

- `duplicate_units.json`: duplicate `$.frame.units` JSON member.
- `missing_layer.json`: unknown surface `layer_id` reference.
- `crossed_collision_polygon.json`: self-intersecting physical polygon.

The CLI must return exit 2 with a structured error. Additional negative and
boundary cases are generated by `tests/test_arena_format.py`.
