# RMUC 2027 雷达标记模块 v1

`rmuc2027-radar-v1.0.0-module.1`。依据固定手册 [`docs/rules/`](../../docs/rules/README.md)，页码为印刷页码。

雷达识别这一半的规则算术：每台地面机器人的“被标记进度”P、易伤阈值、“双倍易伤”机会，以及干扰波难度的比较。
输入是**已裁定事实**：每次收到的坐标按它与真实位置的距离分级。本模块不做视觉、定位或无线电。

## 已实现

| 内容 | 出处 |
|---|---|
| 识别误差分级：d<0.8m 准确，0.8m≤d<1.6m 半准确，d≥1.6m 错误（`classify`） | §5.7.4，p112 |

| 数据中断：每累计 0.5 秒未收到数据视为一次“错误”判定 | 表 5-29，p112 |
| 手册例题逐步复算：1、3、6、10、15 → 3.0 秒 120 → 119.2、117.6、115.2、112、108 → 中断 1 秒 103.2、97.6 → 98.6、100.6 | p113 |
| 复活后 P 保留、x 重置为 0（`revived`） | p113 |
| 表 5-30 对方机器人：[0,100) 无效果，[100,120) 15% 易伤，[120,150] 20% 易伤（与 buff_v1 的副本对全部 P 值核对） | 表 5-30，p113 |
| 双倍易伤：累计使对方机器人易伤 1 分钟得 1 次机会（多台同时易伤不累加），触发后雷达来源的易伤翻倍 30 秒，每局至多触发 2 次 | p113 |

P 与 x 以十分位整数保存（表 5-29 的每一步都是 0.1 的整数倍），全程无浮点。

## 工程选择（手册未写明处）

- **同一毫秒的先后**：到期的中断判定先于同一毫秒到达的数据（timer-before-input，与本仓库其他模块一致）。
  例如恰好隔 0.5 秒才到的一次数据，会先被判一次中断。
- **双倍易伤的上限**：已获得未用的机会数 + 已触发次数不超过 2，达到后不再累计时间。
- **双倍易伤不重叠**：一段 30 秒未结束时再次触发被拒绝（`AlreadyActive`）；生效期间的易伤时间照常计入下一次机会。
- **“当对方干扰波难度高于己方”的读法**：`level(队伍)` 是该队雷达基座上那台干扰源（载有对方密钥、由该队雷达解析）的难度。
  解析得更多的一方不会被对方雷达标记出易伤，对方也不因此累计双倍易伤进度：
  `marks_effective(marker)` 当且仅当 `level(被标记方) ≤ level(marker)`。
- **三级封顶**：难度到三级后再次解析成功不再变化。干扰波各等级的具体参数手册写明“后续发布”。
