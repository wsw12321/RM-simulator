# RMUC 2027 发射与底盘限制模块 v1

`rmuc2027-limits-v1.0.0-module.1`。依据固定手册 [`docs/rules/`](../../docs/rules/README.md)。

## 已实现

| 内容 | 出处 |
|---|---|
| 射击初速度超限：17mm 超出 (0,5) m/s 锁 15 秒、[5,10) 锁 20 秒、≥10 当局永久；42mm 不超过 18 m/s 锁 15 秒、超过 18 m/s 永久；与其他锁定原因独立 | §5.1.2 表 5-3，p66 |
| 底盘功率缓冲能量：上限 60 J，10 Hz 结算 `Z = Z − (Pr − Pl)×0.1`，Z ≤ 0 时断电 5 秒；战亡重置为上限 | §5.1.4 图 5-2，p67–68；§5.3.2 p74 |
| 底盘功率上限合成：功率增益取最大再乘姿态系数；强化移动姿态 200 W；兑换立即复活后提高 1 倍但不超过 200 W | 表 5-28 p109，§5.3.2 p75 |
| 通用射击热量：17mm 每发 +10、Q2 = Q0+100；42mm 每发 +100、Q2 = Q0+200；10 Hz 冷却；升级时可在任意时刻切换上限与冷却；强化进攻姿态热量恒为 0 | §5.1.3 图 5-1，p66–67；表 5-28 |

17mm 部分与原有 `rmuc2027_heat_v1`（保持不变）在固定参数下逐步等价：测试用随机事件序列做了 27 万次差分比较。
Q2 相等时的边界冲突沿用 heat_v1 的三种策略。

## 工程选择 / 未决

- 锁定期间再次超速：默认 `StrictRejectUnadjudicated` 拒绝（手册只写“时间不累加”）；`EngineeringMaxDeadlineV1` 取 max(当前结束, 现在+时长)。
- 断电期间按零功率结算，缓冲能量因此回升。
- 功率以 mW、能量以 µJ 的整数计算；热量边界固定为“同一 100ms 边界先冷却后计发射”、“同刻先计发射后死亡清零”。

## 未实现

缓冲能量增益的来源数值、超级电容、测速模块离线锁定。
