# RMUC 2027 经济与允许发弹量模块 v1

`rmuc2027-economy-v1.0.0-module.1`。全队金币账户与单台机器人允许发弹量账本，均为原子操作。
兑换地点、是否脱战等资格由调用方判断后传入。依据固定手册 [`docs/rules/`](../../docs/rules/README.md)。

## 工程选择

- 价格公式中的“比赛剩余时长”按精确毫秒换算，任何不足一单位的部分都向上取整。
- 周期金币以完成时刻为起点，每满 10 秒结算一次。
