## 工程选择

- 热量冷却合成值四舍五入到整数 / 秒（手册写“取整数值”未说明方向）。
- 进入或退出强化姿态也计入 5 秒切换冷却；强化时间同时计入其基础姿态的累计时长（与例题 2 一致）。
- 同一种地形增益再次获得时刷新为 max(剩余, 初始时长)，不触发 50% 组合。
- “首次获得”经验按高地 / 公路 / 隧道三类计，跨越与穿越隧道同属一类。
- 空中冲击也受无敌阻挡。
