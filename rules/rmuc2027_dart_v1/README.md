# RMUC 2027 飞镖系统模块 v1

`rmuc2027-dart-v1.0.0-module.1`。依据固定手册 [`docs/rules/`](../../docs/rules/README.md)，页码为印刷页码。

一方飞镖发射站的规则：闸门机会与时序、目标选择、检测窗口，以及一次命中除伤害之外的全部收益。
输入是**已裁定事实**：指挥手指令、检测到的发射、检测到的命中。本模块不做飞行与制导；
飞镖的原始伤害在表 5-2（[`buff_v1::raw_damage`](../rmuc2027_buff_v1/README.md)）。

`HitEffect` 给出一次命中的全部收益，`Snapshot` 保存对方被遮挡、增益失效、增益点失效的截止时刻。
`max_hp_loss` 把百分比换算成血量（四舍五入）。每次调用先结算闸门时间线；出错时状态不变。

## 工程选择（手册未写明处）

- **闸门闭合耗时**：手册只给了开启约 7 秒，闭合同样按 7 秒；冷却从完全闭合时开始。
- **默认目标**：从未选择时为前哨站。
- **命中序号**：首次 / 第二次……按本方当局全部有效命中计数（含移动目标）。
- **遮挡叠加**：手册在移动目标一条写“若连续命中，则被遮挡时间叠加计算”，本模块对所有目标都叠加；
  增益暂时失效的时长同样叠加。
- **“4 发全部命中基地”**：固定与随机固定目标下对基地的有效命中合计达到 4 次（两次开启之间可以换这两种目标）。
- **只认所选目标**：选前哨站时命中基地检测模块（或相反）视为无效。
- **同一毫秒的先后**：计时器先于同一毫秒的输入，例如恰在发射窗口结束那一毫秒的发射被拒绝。
- **每发飞镖只结算一次**：`hit` 与 `missed` 各消耗一枚在飞的飞镖，没有在飞的飞镖时报 `NoDartInFlight`。
- **扣血取整**：上限血量 × 百分比按 §5.6.4.1 四舍五入。这笔扣血是否受无敌影响由调用方决定。

## 未实现
