## 时间约定

调用方每个 tick 先 `advance(t, context)` 结算时间相关的变化（读条秒、复活、保护到期、虚弱解除、远程回血、整秒回血），
再在**同一个 t** 上施加该时刻的事实（发射、扣血、兑换等）。未先结算就施加事实会返回 `UnsettledTime`，
避免漏掉中间的回血或读条时刻。

## 工程选择（手册未写明）

- 读条长度先按公式四舍五入，再除以 λ 后**再四舍五入一次**；剩余时间按精确毫秒计算。
- 回血在比赛整秒时刻结算；脱战判定在该时刻进行；6 秒整视为已脱战。
- 远程回血按**生效时刻**的上限血量和 λ 计算（“此时上限血量”）。
- 读条复活至少保留 1 点血。
